Agentry

Who sent this request?A browser, a phone, a crawler or an AI agent.

Agentry is a Ruby gem that reads the User-Agent header, the line of text every browser and crawler sends with a request, and tells you the browser, the operating system, the device or the bot behind it. It is a fork of the browser gem: the same API, faster, with a bot list updated every week.

25 µs per request instead of 126 µs with browser, 2.0 µs once a user agent was seen (YJIT). Of the 882 crawler user agents added to crawler-user-agents since 2024 (test drivers and scanners left out), browser misses 353 and Agentry 11.

gem "agentry"

Quick start

Gemfile

gem "agentry" # Ruby 3.3 or later

Rails view

<% if browser.bot? %>
  <p>Hello, <%= browser.bot.name %>.</p>
<% end %>

Ruby

require "browser"

browser = Browser.new(iphone_user_agent)
browser.name           # => "Safari"
browser.platform.name  # => "iOS (iPhone)"
browser.device.mobile? # => true

browser = Browser.new(gptbot_user_agent)
browser.bot?           # => true
browser.bot.name       # => "ChatGPT"
browser.bot.category   # => :ai_crawler

Why Agentry

The browser gem, unchanged

Code written for browser runs as it is: every predicate, every require path and the Browser namespace keep working, and browser’s own test suite runs unmodified. Switching is one line of the Gemfile.

Migrating

A bot list that stays fresh

Synced every week from crawler-user-agents and ai.robots.txt, both MIT, through a pull request that lists every answer it changes.

Coverage

Bots by category

bot.category tells an AI crawler from a search engine or a scanner, bot.ai? and bot.user_triggered? an agent acting for a person. Test drivers never become bots, so your system tests don’t either.

Categories

Real Googlebot or not

Anyone can send Googlebot. bot.verified?(ip) checks the IP against the ranges Google, Bing, OpenAI, Apple, Perplexity and DuckDuckGo publish, in memory. Behind Cloudflare, browser.cloudflare reads what Cloudflare verified.

Verified crawlers

The same answers, proven

Both gems run over 20,328 user agents on every pull request: an answer that differs from browser’s is either listed as intended or fails the CI.

The corpus

Current Ruby and Rails

Ruby 3.3 or later, tested on Rails 8.0 and 8.1. A browser helper in every controller and view, Client Hints read for Windows 11, and a cache that makes a returning visitor cost a hash lookup.
